OpenSkopos

An open format for what a team agrees before an AI agent builds the work: goals, requirements, rules, assumptions, and the reasons behind them. Every item has a stable ID that people, commits and agents can cite.

Open and vendor-neutral

The specification, the JSON Schema and the reference implementation are under the Apache License 2.0. The format belongs to no vendor. Any tool can read and write it, with no account and no fee. GOVERNANCE.md says who decides on changes.

Reference user

Clarvelo facilitates the team sessions that produce OpenSkopos documents. Any tool can use the format without Clarvelo.

Version 0.1 is in draft. Follow the work on GitHub.
