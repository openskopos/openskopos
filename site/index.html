OpenSkopos

An open format for the decisions that a team makes before an AI agent builds the work: goals, requirements, rules, assumptions, and the reasons behind them. Every item has a stable ID that people, commits and agents can cite.

Before spec-driven development

An OpenSkopos document captures how a team thought the work through before implementation starts: what the work is for, how the team will know it worked, which rules apply, what the team assumes, what could go wrong, and which questions are still open.

Spec-driven development tools, such as OpenSpec, GitHub Spec Kit and Kiro, give an AI agent a spec before it writes code. The OpenSkopos document comes before that spec. The skopos tool exports the document to each of these tools, so the spec starts from what the whole team decided.

Open and vendor-neutral

The specification, the JSON Schema and the reference implementation are under the Apache License 2.0. Any tool can read and write the format. GOVERNANCE.md says who decides on changes.
