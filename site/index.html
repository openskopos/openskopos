OpenSkopos

An open format for the decisions that a team makes before an AI agent builds the work: goals, requirements, rules, assumptions, and the reasons behind them. Every item has a stable ID that people, commits and agents can cite.

Before spec-driven development

An OpenSkopos document records the structured thinking of a team before implementation starts. It holds what the work is for, how the team knows that it worked, the rules, the assumptions, the risks and the open questions.

Spec-driven development tools, such as OpenSpec, GitHub Spec Kit and Kiro, give an AI agent a spec before it writes code. The OpenSkopos document comes first. The skopos tool exports the document to each of these tools. Thus the spec starts from the decisions of the team, not from the guesses of one person or one agent.

Open and vendor-neutral

The specification, the JSON Schema and the reference implementation are under the Apache License 2.0. No company owns the format. Any tool can read and write it. You do not need an account, and you do not pay a fee. GOVERNANCE.md says who decides on changes.
