OpenSkopos

An open format for the decisions that a team makes before an AI agent builds the work: goals, requirements, rules, assumptions, and the reasons behind them. Every item has a stable ID that people, commits and agents can cite.

Open and vendor-neutral

The specification, the JSON Schema and the reference implementation are under the Apache License 2.0. No company owns the format. Any tool can read and write it. You do not need an account, and you do not pay a fee. GOVERNANCE.md says who decides on changes.

Reference user

Clarvelo facilitates team sessions that produce OpenSkopos documents. Other tools can use the format without Clarvelo.
