# Governance

## During 0.x

While the format is at 0.x, the maintainers decide on all changes to the
specification, the schema and the conformance cases.

The maintainer is Joe Corcoran (`joecorcoran` on GitHub).

- Anyone can open an issue or a pull request.
- The maintainers discuss changes in issues and pull requests, in public.
- A change is decided when a maintainer merges its pull request.
- [spec/CHANGELOG.md](spec/CHANGELOG.md) lists each change to the format.

## Before 1.0

Before the format reaches 1.0, the maintainers will review this document. The
review will decide how other people and organizations can become maintainers,
and how the project decides when maintainers do not agree.
